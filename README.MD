# Mundo Minecraft

## Sobre o Projeto

Este projeto foi desenvolvido como uma atividade prática de **HTML e CSS**, com o objetivo de criar um site informativo sobre o universo do Minecraft.

O site apresenta informações sobre o jogo, seus biomas, criaturas, construções e dicas para explorar e sobreviver nesse mundo de blocos.

## Objetivos

- Praticar a estruturação de páginas com HTML.
- Aplicar estilos utilizando CSS.
- Criar um menu de navegação entre diferentes páginas.
- Organizar textos, títulos, imagens e seções.
- Desenvolver uma página com identidade visual inspirada no Minecraft.

## Páginas do Site

- **Primeira Tela:** apresentação do mundo Minecraft.
- **Segunda Tela:** exploração dos biomas.
- **Terceira Tela:** informações sobre os monstros e animais.
- **Quarta Tela:** construções e possibilidades dentro do jogo.
- **Quinta Tela:** dicas de sobrevivência e conclusão.

## Tecnologias Utilizadas

- **HTML5:** estrutura e organização do conteúdo.
- **CSS3:** cores, espaçamentos, fontes e layout.
- **Visual Studio Code:** editor utilizado no desenvolvimento.

## Identidade Visual

O design foi inspirado nas cores características do Minecraft:

- Verde: grama e natureza.
- Marrom: terra e madeira.
- Cinza: pedras e blocos.
- Preto: contraste no menu lateral.
- Branco: legibilidade dos textos.

## Aprendizados

Durante o desenvolvimento, foram praticados conceitos de estruturação HTML, estilização CSS, inserção de imagens, criação de menus de navegação e organização de arquivos.
